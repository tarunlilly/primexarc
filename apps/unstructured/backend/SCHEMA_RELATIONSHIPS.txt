================================================================================
DATABASE SCHEMA RELATIONSHIP DIAGRAM
================================================================================

CORE FOUNDATION TABLES
======================

users
  ├── id (UUID, PK)
  ├── email (UNIQUE)
  ├── auth_provider (authprovider ENUM)
  ├── deleted_at (soft delete)
  └── [password fields, verification fields, profile fields]

workspaces
  ├── id (UUID, PK)
  ├── owner_id → users (FK)
  ├── deleted_at (soft delete)
  └── settings (JSON)

workspace_members
  ├── id (UUID, PK)
  ├── workspace_id → workspaces (FK)
  ├── user_id → users (FK)
  ├── role (workspacerole ENUM)
  └── UNIQUE(workspace_id, user_id)

================================================================================
PRODUCT MANAGEMENT
===================

products
  ├── id (UUID, PK)
  ├── workspace_id → workspaces (FK)
  ├── owner_user_id → users (FK)
  ├── status (productstatus ENUM)
  ├── current_version (INTEGER)
  ├── promoted_version (INTEGER)
  ├── chunking_config (JSON)
  ├── embedding_config (JSON)
  ├── deleted_at (soft delete)
  └── [S3 paths, AIRD fields, policy fields, metrics, etc.]
       │
       ├─→ data_sources ──┐
       │    ├── id (UUID, PK)
       │    ├── workspace_id → workspaces (FK)
       │    ├── type (datasourcetype ENUM)
       │    └── config (JSON)
       │
       ├─→ raw_files
       │    ├── id (UUID, PK)
       │    ├── workspace_id → workspaces (FK)
       │    ├── product_id → products (FK)
       │    ├── data_source_id → data_sources (FK)
       │    ├── version (INTEGER)
       │    ├── status (rawfilestatus ENUM)
       │    ├── storage_key (VARCHAR, UNIQUE)
       │    ├── storage_bucket (VARCHAR)
       │    └── [file metadata, checksums, timestamps]
       │
       ├─→ dq_violations
       │    ├── id (UUID, PK)
       │    ├── product_id → products (FK)
       │    ├── version (INTEGER)
       │    ├── pipeline_run_id → pipeline_runs (FK)
       │    ├── severity (dqviolationseverity ENUM)
       │    └── [rule info, details, counts]
       │
       ├─→ data_quality_rules
       │    ├── id (UUID, PK)
       │    ├── product_id → products (FK)
       │    ├── workspace_id → workspaces (FK)
       │    ├── status (rulestatus ENUM)
       │    ├── severity (ruleseverity ENUM)
       │    ├── parent_rule_id → data_quality_rules (FK, self-referential)
       │    ├── configuration (JSON)
       │    └── [audit fields, timestamps]
       │
       ├─→ pipeline_runs
       │    ├── id (UUID, PK)
       │    ├── workspace_id → workspaces (FK)
       │    ├── product_id → products (FK)
       │    ├── version (INTEGER)
       │    ├── status (pipelinerunstatus ENUM)
       │    ├── metrics (JSON)
       │    ├── [AIRD tracking, S3 paths, timestamps]
       │    │
       │    ├─→ pipeline_artifacts
       │    │    ├── id (UUID, PK)
       │    │    ├── pipeline_run_id → pipeline_runs (FK)
       │    │    ├── workspace_id → workspaces (FK)
       │    │    ├── product_id → products (FK)
       │    │    ├── version (INTEGER)
       │    │    ├── artifact_type (artifacttype ENUM)
       │    │    ├── status (artifactstatus ENUM)
       │    │    ├── retention_policy (retentionpolicy ENUM)
       │    │    ├── storage_key (VARCHAR)
       │    │    ├── storage_bucket (VARCHAR)
       │    │    ├── created_by → users (FK)
       │    │    └── [checksums, metadata, timestamps]
       │    │
       │    └─→ eval_runs (if used)
       │         ├── id (UUID, PK)
       │         ├── workspace_id → workspaces (FK)
       │         ├── product_id → products (FK)
       │         ├── pipeline_run_id → pipeline_runs (FK, SET NULL)
       │         ├── version (INTEGER)
       │         ├── status (VARCHAR)
       │         └── metrics (JSON)
       │
       ├─→ document_metadata
       │    ├── id (UUID, PK)
       │    ├── product_id → products (FK)
       │    ├── version (INTEGER)
       │    ├── chunk_id (VARCHAR)
       │    └── [file info, page numbers, fields, tags]
       │
       ├─→ vector_metadata
       │    ├── id (UUID, PK)
       │    ├── product_id → products (FK)
       │    ├── version (INTEGER)
       │    ├── collection_id (VARCHAR)
       │    ├── chunk_id (VARCHAR)
       │    └── [page numbers, sections, fields, tags]
       │
       └─→ acls
            ├── id (UUID, PK)
            ├── user_id → users (FK)
            ├── product_id → products (FK)
            ├── access_type (aclaccesstype ENUM)
            └── [scopes: index, doc, field]

================================================================================
QUALITY & COMPLIANCE
====================

data_quality_rule_sets
  ├── id (UUID, PK)
  ├── workspace_id → workspaces (FK)
  ├── status (rulestatus ENUM)
  └── [versioning, framework, classification, audit fields]
       │
       └─→ data_quality_rule_assignments
            ├── id (UUID, PK)
            ├── rule_set_id → data_quality_rule_sets (FK)
            ├── product_id → products (FK)
            ├── assigned_by → users (ID, not FK)
            └── [override tracking]

data_quality_rule_audit
  ├── id (UUID, PK)
  ├── rule_id → data_quality_rules (FK)
  ├── action (auditaction ENUM)
  ├── changed_by → users (ID, not FK)
  └── [old/new values (JSON), session tracking, IP address]

data_quality_compliance_reports
  ├── id (UUID, PK)
  ├── workspace_id → workspaces (FK)
  ├── generated_by → users (ID, not FK)
  └── [report data (JSON), period tracking]

billing_profiles

  ├── yaml_content (TEXT)
  ├── is_active (BOOLEAN)
  └── UNIQUE(workspace_id, playbook_id)

================================================================================
RELATIONSHIPS SUMMARY
====================

Multi-Tenancy Structure:
  workspaces (root)
    → users (via workspace_members for membership)
    → products (owned by users, within workspaces)
    → data_sources (belong to products)
    → raw_files (belong to products via data_sources)
    → pipeline_runs (execute for products)
    → dq_violations (related to products)
    → billing_profiles (one per workspace)
    → custom_playbooks (belong to workspaces)

Data Ownership Chains:
  workspace_id → product_id → version → raw_files
  workspace_id → product_id → version → dq_violations
  workspace_id → product_id → version → document_metadata
  workspace_id → product_id → version → vector_metadata
  workspace_id → product_id → pipeline_runs → pipeline_artifacts

User Access:
  users → workspace_members → workspaces → products
  users → acls → products (fine-grained access control)

Quality Control:
  products → data_quality_rules
  data_quality_rules → data_quality_rule_audit (audit trail)
  data_quality_rule_sets → data_quality_rule_assignments → products

KEY CONSTRAINTS & INDEXES
==========================

Unique Constraints:
  - users(email)
  - users(google_sub)
  - users(verification_token)
  - users(password_reset_token)
  - workspace_members(workspace_id, user_id)
  - products(workspace_id, name)
  - raw_files(storage_key)
  - raw_files(product_id, version, file_stem)
  - billing_profiles(stripe_customer_id)
  - custom_playbooks(workspace_id, playbook_id)

Soft Delete Support (deleted_at):
  - users
  - workspaces
  - products

Foreign Key Cascade Rules:
  - eval_queries → products (CASCADE DELETE)
  - eval_queries → workspaces (CASCADE DELETE)
  - eval_runs → products (CASCADE DELETE)
  - eval_runs → workspaces (CASCADE DELETE)
  - eval_runs → pipeline_runs (SET NULL)
  - pipeline_artifacts → created_by (FK, no action)

Performance Indexes:
  - idx_products_workspace_status
  - idx_products_workspace_version
  - idx_products_workspace_created_at
  - idx_products_workspace_active (partial: WHERE deleted_at IS NULL)
  - idx_pipeline_artifacts_product_version_type
  - idx_raw_files_product_version_status
  - idx_dq_violations_product_severity
  - idx_pipeline_runs_workspace_status_created
  - idx_eval_runs_product_version
  - idx_eval_queries_product_version
